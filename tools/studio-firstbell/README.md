Run `npm run setup:check` in this directory for a bounded, secret-free prerequisite report. It validates the pinned official configuration module, verifies read-only rails and checks whether a local encrypted-wallet file and password entry exist. Presence does **not** prove authentication. The command never unlocks a wallet, provisions an account, imports application secrets, pays, registers an identity or deploys cloud resources. On Windows it reports secret permissions as unverified because Unix mode bits cannot establish a Windows ACL.

Run `npm run mcp` to start the actual stdio MCP face. A compatible MCP client launches this command as its subprocess. When the official `bag dev` launcher supplies `AGENT_PORT`, the same entrypoint serves Streamable HTTP at `http://127.0.0.1:<port>/mcp`. It binds only loopback, rejects browser origins and unexpected host headers, bounds request bodies, and exposes only `review_public_bell`. Local HTTP access confers no wallet or payment authority. Both transports are verified with actual MCP SDK clients.
