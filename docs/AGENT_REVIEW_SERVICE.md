# Persistent private Bell review service

First Bell provides a purposeful read-only task service that prepares structured source-grounded Bell review reports. It is deterministic and uses actual signed Binance discovery briefs. It does not claim to be an analyst, AI model, BNB Agent Studio runtime, deployed onchain agent identity or paid research provider.

POST `/api/agent/reviews` accepts only `{requestId:uuid,bellId,bellVersion,bellContentHash}` and returns `{job}` (202 on admission, 200 on immutable replay). The current verified wallet session determines owner and revocable grant. Bell versions/hash are verified from stored immutable definitions; personal policy/version are captured at admission. No caller wallet, account, scope or financial authorization is accepted. GET `/api/agent/reviews/[id]` reads only owned jobs. DELETE cancels only owned pending/running work. All routes enforce secure identity transport; mutations also enforce same origin. Bodies are bounded, admissions rate limited, and results private/no-store/nosniff.

SQLite atomic admission limits each owner to two active jobs and 500 lifetime jobs, with forty active globally. Before global counts, all pending/running jobs are swept for revoked grants and the 180-second total deadline. Only hashes of identity tokens are persisted. Session revocation cancels work before further source reads and report publication; completed historical reports remain owner-private.

Workers claim jobs atomically with a 30-second lease. Subsequent authenticated GET polling may recover pending work or an expired running claim after process interruption. A new claim fences all old worker output, and cancellation/expiry/revocation prevent publication. Source reads can repeat during lease recovery because they are read-only. Jobs that exceed the total deadline fail honestly. Recovery is polling-triggered, not a claimed autonomous background runtime. No payment or financial operation is retried.

Reports contain captured Bell ID/version/hash, personal/effective rules, per-asset target versus exposure limit, reserve target versus effective requirement, actual source timestamps, supported token representations and explicit factual-only limitations. There are no price forecasts, recommendations, fabricated fundamentals or ratings. The report can inform a later human-reviewed action but never saves a Bell/policy, activates Autopilot or authorizes execution.

CLI entry source loads wallet/session/config modules before static diagnostics. No CLI bootstrap, credential loading, deployment or signer is invoked by this service. The advertised repository URL returned unavailable during this review; safe runtime adapter/identity/cloud operation remain unverified. Existing `studio-project.ts` remains a disabled diagnostic, not operational evidence. This service does not satisfy the Studio or paid research acceptance gates by itself.

Tests: `node --test tests/agent-review.test.ts` exercises source provenance/freshness, original captured-policy replay, ownership, bounded queues, reopened lease recovery, old-claim fencing, cancellation, revocation, global stale cleanup and immutable completed reports. Synthetic test briefs do not establish live integration evidence.
