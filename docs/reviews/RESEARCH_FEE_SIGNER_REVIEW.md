# Research fee authority and signer review

Reviewed `lib/research/fee-authority.ts`, `app/api/research/stockanalyst/route.ts`, `lib/agents/research-signer.ts` and its isolated CLI runner on October 10, 2026. Independent Codex review; no financial flags changed, payment performed or authenticated CLI executed.

No concrete authority bypass found in the reviewed source. The route derives owner and wallet through the existing secure identity transport boundary. Financial approval requires the mainnet, execution mode and research-specific flags together. Offer identity, wallet, asset, amount and parent session digest are checked before approval or claim. The server validator checks session revocation and expiration. Claimed fees remain reserved after expiry and cannot be revoked into a released budget.

The isolated signer has no HTTP caller. It checks exact typed payment data, explicit digest confirmation, operator wallet/session, provider preview and cryptographic signature recovery. Its durable unique authority/nonce record precedes execution and prevents retry after an ambiguous result. Research signing grants no stock trading scope.

Eight initial targeted tests passed independently. A subsequent run of six fee-authority tests and four StockAnalyst submission tests also passed. Added regressions cover parent-session revocation before approval/claim and during private signing; missing session validation fails closed. Final follow-up independently passed six submission and four private job tests, including ignored aborts, late signatures, hanging fetch/body readers, encrypted owner-bound tokens and malicious download URL rejection. The overall deadline now races every external await and retains durable UNKNOWN without late submission. Paid-research UI resets busy state on ticker changes and clears offer/grant state on authentication failure.

The private job route derives the current authenticated owner, requires configured server AES key, looks up only that owner's encrypted job and rechecks identity after provider awaits. Status/report/resume returns neither the job bearer token nor presigned download URL and sends no new payment. No remaining concrete blocker found in this reviewed scope. Tests use synthetic provider responses and signatures; they do not prove a production payment or analyst report. Exact request-body hashing, grant claim, signature recovery and fixed-origin submission were reviewed without invoking payment.
